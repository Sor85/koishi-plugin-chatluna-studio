# 使用共享模型证据投影驱动轨迹与对话视图

模型请求记录及其中的原始模型证据继续作为权威事实，不新增持久化副本或 Console RPC；请求轨迹与模型请求对话视图在读取时共同调用位于 `src` 的浏览器安全纯模型证据投影 module，通过一个小 interface 从请求体、响应原文和响应 transport 格式派生分别有序的请求消息、工具定义与响应语义事件。

协议识别采用 shape-driven internal adapter，不依赖仅用于展示的 provider、域名或未持久化的协议枚举；每个投影项必须保留确定性的 evidenceId 及一个或多个原始证据来源，局部不支持、损坏或歧义以结构化诊断返回，明确调用标识缺失时不得按名称或位置推断工具调用与工具结果关系，未知 SSE 结构也不得通过通用字符串拼接猜测语义。

共享投影 module 是唯一理解 OpenAI、Anthropic、Gemini、Responses、AI SDK 及 JSON、text、SSE 证据结构的 module；服务端模型请求轨迹只负责会话聚合、请求边界、时间和组成统计，客户端模型请求对话视图及分析导航只负责显示投影、搜索、定位与交互，迁移时按请求证据、响应证据、稳定身份的顺序直接替换并删除对应旧解析，不保留双解析或兼容 fallback。
