# QQ 头像地址在客户端按号码算出，不写进记录

列表与详情里的机器人、群与好友头像由客户端从平台与号码拼出 `q.qlogo.cn` / `p.qlogo.cn` 地址，服务端不把地址写进记录，也不代为下载。插件配置里有一个开关；关掉后只显示首字母色块，浏览器不向腾讯 CDN 发出任何请求。

**为什么不写进记录。** 头像地址是一个由号码算出的公开地址，不是采集到的事实。让服务端写进每条记录，等于把一个纯展示决定（要不要外链）冻结进持久化数据里：用户改了开关，旧记录仍然带着地址；而地址格式一旦变化，历史记录里的那份也不会跟着变。这与 [ADR-0003](./0003-snapshot-conversation-identity-with-each-request.md) 快照名称不冲突——名称是当时的现场，会变且必须留住；地址是当下的推导，随时可以重算。

**只有 QQ 系平台的号码能拼。** 判据是平台白名单加号码格式，两者都满足才拼。别的平台上同样是数字的账号拼出来会是某个陌生 QQ 用户的头像——一个不会报错、只会显示错人的失败形态。

代价是控制台会向腾讯 CDN 发请求，把 QQ 号暴露在请求地址里；这是开关存在的理由，而不是把开关默认关掉的理由：真实环境里认人靠头像比认号码快得多。
