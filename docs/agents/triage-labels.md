# Triage Labels

工程 Skills 使用五个固定角色描述 Issue 状态。本文件定义这些角色在当前仓库中对应的标签字符串。

| Skill 角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已经明确，可交给 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 不会处理 |

当 Skill 使用某个 Triage 角色时，必须使用表格中对应的仓库标签。

如需调整标签词汇，只修改表格的“本仓库标签”列。
